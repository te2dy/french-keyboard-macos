# Clavier français pour macOS

Liste des raccourcis :

|  Raccourci |  Caractère correspondant | Signification |
|---|---|--|
|  ' |  ’ |  apostrophe courbe |
|  ⌥ + ' |  ' | apostrophe droite |
|  ⌥ + barre d’espace |   | espace fine |
|  ⌥ + " |  «  | guillemet français ouvrant |
|  ⌥ + ⇧ + " |  » | guillemet français fermant |
|    ⌥ + è    |  ‹ |  guillemet français simple ouvrant  |
|    ⌥ + ⇧ + è    |  › |  guillemet français simple fermant  |
|      ⌥ + x      |  × |    croix de multiplication   |
|      ⌥ + ⇧ + x      |  𝕏 |    majuscule mathématique ajourée X   |
|        ⌥ + n        |  ≈ |     valeur approchée     |
|         $         |  € |      euro     |
|         ⌥ + $         |  $ |      dollar
